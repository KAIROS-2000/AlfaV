# Руководства по ролям

Выберите свою роль:

- [Суперадминистратор](superadmin.md) — управление администраторами, менеджерами и всеми рабочими разделами.
- [Администратор](admin.md) — пользователи, учебный контент, обращения и контроль работы платформы.
- [Учитель](teacher.md) — классы, уроки, задания и проверка работ.
- [Менеджер](manager.md) — контакты и адресные рассылки.

Во всех инструкциях названия кнопок и разделов соответствуют текущему интерфейсу Progyx. Если раздел не открывается, убедитесь, что вы вошли под нужной ролью и учётная запись активна.
